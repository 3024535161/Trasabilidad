KAGE LIVE MINI PRO
Publica index.html y avatar.webp en la raiz de GitHub Pages.
El archivo KAGE-LIVE-ABRIR.html integra la imagen y se puede abrir directamente.
El enlace ?mode=remote&pin=1234 abre el control remoto.
La conexion por PIN necesita internet y confirmacion manual en el telefono principal.
Las canciones de animes existentes deben cargarse como archivos de usuario y se recomienda contar con derechos para transmitirlas.
Tambien hay tres melodias sinteticas originales para reproducir desde el control remoto.
