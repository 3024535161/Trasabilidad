# KAGE LIVE V10 ULTRA

Versión avanzada del avatar anime para directos.

## Funciones principales
- Avatar frontal integrado.
- Boca con visemas múltiples.
- Tracking facial experimental por cámara.
- Control remoto desde segundo dispositivo.
- Groove improvisado con Web Audio.
- Auto baile, escenas, regalos y frases habladas.
- Modo LIVE limpio sin controles visibles.

## Archivos
- `index.html`: versión para publicar en GitHub Pages.
- `avatar.webp`: imagen del avatar.
- `manifest.webmanifest`: manifiesto básico.

## Recomendación
Publicar con HTTPS para permisos de micrófono y cámara.
